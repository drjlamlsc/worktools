Prescription Calculator v7

1. Full prescription with overall duration

Example: "Brintellix 20mg daily, Quetiapine 50mg noct, Xanax 0.25mg BD PRN"

2. Prescription with specific durations for some medications

Example: "Brintellix 20mg daily, Xanax 0.25mg BD PRN x 1 week"

3. Specify dose strength using [strength]

Example: "Lamotrigine 100mg Nocte [25mg]" (dispense 25mg × 4)

4. Direct dispensation format

Example: "Latuda 20mg x 14" (dispense 14 tabs)

5. Medications that can't be split (prefix with *)

Example: "*Fluoxetine 30mg daily" (finds optimal combination of available strengths)

6. Force brand or generic (prefix with $ or #)

Example: "$pregabalin 75mg TDS" (forces brand LYRICA), "#lyrica 75mg TDS" (forces generic)
